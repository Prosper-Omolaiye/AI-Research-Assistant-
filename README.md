# AI Research Assistant

A Langflow workflow that summarizes any article instantly 
using just a URL.

## What it does
- Takes any article URL as input
- Fetches and reads the full article content
- Returns a clean, concise summary using Gemini Flash

## Tools Used
- Langflow
- Google Gemini Flash

## How to use
1. Download the workflow JSON file
2. Import it into your Langflow or n8n instance
3. Add your Gemini API key
4. Paste any article URL and get a summary instantly

## Use case
Perfect for researchers, students, and professionals 
who need quick insights without reading full articles.
